# > HELLO !

This repo exists for one reason: to turn a GitHub contribution graph into pixel art.

Anyone can fake activity — a for-loop with `--allow-empty` and backdated commits gets you a green wall in seconds. But shaping it into something that actually looks intentional? That takes a bit more effort.

Here, 311 commits are carefully placed across specific dates to spell out `> HELLO !` in the contribution grid, with a gradient from dark to bright green, left to right.

Each commit message is a quote from *Egzorcysta* / *Bogdan Boner: Egzorcysta* by [Bartosz Walaszek](https://egzorcysta.fandom.com/wiki/Cytaty). Polish swear words have been redacted — the spirit remains intact.
